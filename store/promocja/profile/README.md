# Grafiki profili @mygratitudeapp

Zbudowane z grafiki promocyjnej ze sklepu (`store/grafiki/promo-en.png`) i angielskich ekranów aplikacji.
Tworzy je `npm run profile-graphics` (`scripts/make-profile-graphics.mjs`).

| Plik | Rozmiar | Gdzie wgrać |
|---|---|---|
| `avatar-1080.png` | 1080x1080 | zdjęcie profilowe: Facebook (strona), Instagram, TikTok, YouTube, LinkedIn – po przycięciu do koła nic nie znika |
| `facebook-cover.png` | 1640x624 | zdjęcie w tle strony na Facebooku – na telefonie boki się przycinają, tekst zostaje widoczny |
| `youtube-banner.png` | 2560x1440 | baner kanału YouTube – treść w strefie widocznej na każdym urządzeniu (1546x423) |
| `linkedin-cover.png` | 1128x191 | okładka strony firmowej na LinkedIn – lewy dolny róg zakrywa logo, więc treść jest przesunięta w prawo |

Instagram i TikTok nie mają okładek – wystarczy zdjęcie profilowe.
