# Grafiki na TikTok (tryb zdjęć)

Format 1080x1920 (9:16). W TikToku: **+ → Zdjęcia**, zaznacz slajdy w kolejności nazw plików (01, 02, …),
dodaj muzykę z biblioteki TikToka i opis poniżej. Grafiki tworzy `npm run carousels -- tiktok`
(`scripts/make-carousels.mjs`).

Treść jest odsunięta od krawędzi, żeby nie zasłaniały jej zakładki u góry, przyciski po prawej
ani podpis na dole.

Link w bio TikTok pokazuje dopiero od 1000 obserwujących, więc ostatni slajd mówi:
„Wpisz w Google Play: Wdzięczność dziennik”. Publikuj dopiero po zatwierdzeniu wersji produkcyjnej.

---
