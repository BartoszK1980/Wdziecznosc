# Grafiki do postów na Facebooku

Format 1080x1350 (4:5), w 7 językach: `pl/`, `en/`, `de/`, `es/`, `fr/`, `it/`, `pt/`.
Grafiki tworzy `npm run carousels -- facebook`, teksty na grafikach są w `scripts/promo-texts/<język>.mjs`.

Wrzuć grafikę jako zdjęcie, a link do sklepu wpisz w treści posta (w grupach na końcu wpisu
albo w pierwszym komentarzu, jeśli reguły grupy tak wymagają).

**Teksty postów:** `../teksty/<język>.md`, sekcja „Facebook”.
